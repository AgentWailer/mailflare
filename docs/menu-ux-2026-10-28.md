# Menu UX review — 28 October 2026

## Observed problems and changes

The local production build showed categories mixed with folders, labels beyond a long undifferentiated list, inconsistent rounded edges/insets and no permanent settings entry. On phones, the menu used the same hamburger for opening and closing. Settings destinations were two-column tiles that offered little room for longer labels.

- Separate Postfach, Kategorien and Labels, with matching icon/text alignment and a shared active surface.
- Keep Inbox, Starred, All mail, Sent and Drafts directly visible. Further folders expand in place; the active secondary folder and scheduled mail with pending messages remain visible. Expanded/collapsed state is session-local.
- Retain the existing main/more saved order and label ordering. Categories now have their own reorderable group and local order key; their initial order is invoice, orders, promotions, social. They can no longer be dragged between the mail-folder group and category group.
- Persistent Settings footer, desktop keyboard shortcuts, wider mobile drawer, explicit close control, Escape dismissal and focus restoration. Safe-area padding stays outside the scrolling area.
- Settings destinations use full-width grouped rows on phones, with icons and chevrons. Desktop settings use matching icons and an explicit section heading. Existing bottom navigation and direct language/theme fields are retained.
