# Adjust profile pictures

In profile or mailbox settings, choose **Adjust picture** below the current avatar. Drag the image to align the face in the circular preview; use the zoom slider to resize it. Arrow keys also move the picture. **Save picture** uploads the selected crop and updates avatars across the app. Cancel leaves the existing picture unchanged. New uploads use the same preview before saving.

A resized, uncropped WebP source (maximum edge 512 pixels) is retained privately alongside the displayed image and its preview, so future adjustments can start from that source. Existing avatars without this source use their previously stored image. If that image is already cropped, upload the original photo again to recover the missing area. Images remain behind the existing authenticated avatar routes and mailbox permissions; deleting an avatar or its unused account assets removes the source too.
