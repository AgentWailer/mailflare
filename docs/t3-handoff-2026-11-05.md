## Decisions to preserve

- Release reviewed changes through `main` and the existing Cloudflare Builds
  path. A push alone does not prove deployment; verify the active version/traffic.
- Preserve this fork, current resources and architecture. Node/Docker, B2, S3,
  Resend and SES support do not imply a runtime migration is wanted.
- Apply compatible additive database migrations before dependent code; preserve
  migration history. Follow `AGENTS.md` for backup/restore lists when persisted
  tables change. Use [operations.md](operations.md) for release and recovery.
- Respect the 128 MB Worker budget, bounded metadata pagination, streaming, and
  private mail cache boundaries.
- Preserve the fast History API path only for the five category overview pages,
  including stale-reader-response and back-navigation protections.
- Keep protected PDF preview/decryption local to the browser. Do not store PDF
  passwords or replace encrypted originals; load PDF resources on demand.
- Preserve Access authentication plus explicit Mailflare grants for MCP. Sending
  requires a review request and Mailflare confirmation; calendar writes take
  effect immediately under their separate scopes.
- Protect security, debt-collection and transactional correspondence in sorting,
  and preserve manual corrections. Validate sorting changes with representative
  cases. Personal everyday usability, speed and reliability take priority.
